# 케셰브 최종 인수인계·재현 기록 (22단계, 학생 작성)

이 문서는 학생이 직접 실행해 본 재현 기록과 버전 기록입니다. 아래 결과는 학생 진술이며, ALEPH 서버가 새 환경에서 실행해 확인한 것이 아닙니다. 공식 판정은 서버의 AI가 커밋 원문을 읽고 내린 것이고, 실행 성공을 증명하지 않습니다.

## 1. 버전과 상태

| 항목 | 값 |
|---|---|
| 저장소 | https://github.com/chacha1650a/choi-bujang-secret-vault |
| 브랜치 | `main` |
| 재현한 커밋 | `01a1f7b52e4ac4e59a8ede04335b9077c661281a` |
| 앱 폴더 | 저장소 안의 `on-client` |
| 시작 틀 | 0.2.21 (`on-client/package.json`) |
| 학생 버전 이름 | 케셰브 학생판 0.9 (검증 중인 버전) |
| 상태 | 원문 검토 기준 완료. 실제 운영 인증이나 v1.0 아님 |

검증 중인 버전으로 두는 까닭: 실제 접근 제어 서버 연결, 앱 안 AI 실제 연결, 19단계 조치 실집행, 실제 OSV 조회가 아직 준비되지 않았거나 확인하지 못했습니다(4장).

이 문서를 더한 22단계 제출 커밋은 재현한 커밋 뒤에 `on-client/docs/STUDENT_RELEASE.md` 한 파일만 추가한 커밋입니다. 앱 코드(`on-client/student/`, `src/`, `public/`, `tools/`)와 설정 견본은 재현한 커밋과 같습니다. 이 문서를 더한 커밋 자체를 새 폴더에서 다시 실행하지는 않았습니다.

## 2. 재현 환경과 절차

| 항목 | 값 |
|---|---|
| 운영체제 | Windows 11 Pro 10.0.26100 |
| 셸 | PowerShell 5.1, Git Bash |
| Node.js | v24.19.0 (`node --version`) |
| 외부 npm 설치 | 필요 없음(의존성 없음, `npm install` 생략) |
| 새 폴더 | 원래 작업 폴더와 다른 빈 임시 폴더 아래 `vault` (절대경로는 PC마다 다르므로 적지 않음) |
| 재현 시각(UTC) | 2026-11-03T02:44:04Z ~ 02:44:53Z |

원래 작업 폴더는 그대로 두었고, 인증·설정 파일을 복사하지 않았습니다. `.env` 도 만들지 않았습니다.

1. 빈 폴더에서 받기: `git clone https://github.com/chacha1650a/choi-bujang-secret-vault.git vault`
2. 커밋 고정: `git checkout 01a1f7b52e4ac4e59a8ede04335b9077c661281a` → `git rev-parse HEAD` 가 같은 값인지 확인
3. 런타임 확인: `cd vault/on-client` → `node --version` 결과 `v24.19.0`
4. 문법 검사: `node --check student/extension.mjs` (= `npm run check`) 통과
5. 기본 실행(연결 없음): 5189 를 다른 프로그램이 쓰고 있어 포트를 바꿔 `ON_PORT=5198 node src/server.mjs` (= `npm start` 와 같은 서버) 실행 → `케셰브 연결 확인: http://127.0.0.1:5198`
6. 예제 실행: `ON_PORT=5197 node src/server.mjs --demo` (= `npm run demo`) → `케셰브 예제: http://127.0.0.1:5197`
7. 브라우저 확인: 각 주소를 열어 학생 칸 8개를 읽음(3장)
8. 종료: 두 서버 프로세스를 끈 뒤 5197 주소가 열리지 않는 것을 확인(창에서 실행했다면 `Ctrl+C`)
9. 다시 실행: 6번을 다시 실행 → `케셰브 예제: http://127.0.0.1:5197`, 첫 화면 HTTP 200 확인 뒤 종료

`tools/start-alekov.ps1` 로 실행하는 절차(`STUDENT_RUNBOOK.md` 4장)는 이번 재현에서 실행하지 않았습니다(미확인). 이 도구는 계정 연결용 개인 설정을 Windows 사용자 폴더에 만들기 때문에 재현 때 쓰지 않았습니다.

## 5. 다른 환경으로 옮기기

- 필요한 것: Git, Node.js 22~24(수업 기준 24.19.0), PC 브라우저. npm 패키지 설치는 필요 없습니다.
- 받는 것: 저장소 전체를 `git clone` 한 뒤 위 커밋으로 `git checkout` 합니다. 앱은 `on-client` 폴더에서 실행합니다.
- 설정 견본: `on-client/.env.example` (비밀 없음. `ON_PORT`, `ON_ENGINE_ADAPTER`, `ON_AI_MODEL`, `ON_PROJECT_DIRECTORY`, `ON_APPROVED_PUBLIC_PACKAGES`). 서버는 포트를 환경변수 `ON_PORT` 에서 읽고 없으면 5189 를 씁니다.
- 코드와 문서에 로컬 절대경로나 열쇠·토큰을 넣지 않았습니다. 계정 연결 설정은 실행 도구가 각 PC의 Windows 사용자 폴더에 새로 만듭니다.

## 7. 지원 범위와 남은 일

- 지원: Windows PC, Node.js 22~24, 브라우저 1280px 이상, 본인 범위(최근 기록 40건, 현재 세션 1개, 등록 기기 100개까지).
- 지원하지 않음: 휴대폰 화면, 관리자용 전체 직원 조회, 학생 코드에서 서버 직접 요청이나 조치 실행.
- 남은 일(미해결): 실제 접근 제어 서버 연결, 앱 안 AI 실제 연결과 설명 성공, 19단계 조치 실집행과 효과 관측, 실제 OSV 조회, `tools/start-alekov.ps1` 실행 확인.
