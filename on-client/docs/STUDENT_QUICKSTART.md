# 케셰브 한 장 실행 안내 (학생 작성)

처음 보는 사람이 이 한 장만 보고 앱을 켜고 끄는 안내입니다. 자세한 내용은 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md)에 있습니다.

## 필요한 것

- Windows PC, 브라우저(폭 1280px 이상), Git
- Node.js 22~24 (수업 기준 24.19.0). 확인 명령: `node --version`
- npm 패키지 설치는 필요 없습니다.

## 받기

```powershell
git clone https://github.com/chacha1650a/choi-bujang-secret-vault.git
cd choi-bujang-secret-vault\on-client
```

## 켜기

```powershell
npm run demo
```

`케셰브 예제: http://127.0.0.1:5189` 가 보이면 브라우저에서 그 주소를 엽니다. 예제 실행의 사용자·기록은 설명용 값입니다.

회사 서버 없이 켜는 기본 실행은 `npm start` 입니다. 이때는 「연결 없음」과 연결 실패 안내가 보이는 것이 정상입니다.

포트 5189 를 이미 쓰고 있으면 오류 문구 없이 주소 줄이 나오지 않습니다. 그 프로그램은 그대로 두고 PowerShell 에서 포트를 바꿔 켭니다.

```powershell
$env:ON_PORT = '5190'; npm run demo
```

## 처음 볼 곳

1. 왼쪽 메뉴 「보호 현황」 → 학생 상태 칸의 「내 PC 보안 대시보드」에서 「조회」를 누릅니다. 이 값은 예제가 아니라 이 PC에서 잰 실측값입니다. 측정 시각도 함께 보입니다.
2. 「업무 앱」에서 앱 하나의 「접속 요청」을 누릅니다. 예제 실행에서 허용·거부·추가 확인이 서로 다르게 보입니다.
3. 「보안 기록」에서 기록의 상세를 열고 「AI 설명 요청」을 누릅니다. AI 권한이 없으면 「AI 설명 실패」가 보이고 기록은 그대로 남습니다.

## 끄기

켠 PowerShell 창에서 `Ctrl+C` 를 누릅니다. 다시 켤 때는 같은 폴더에서 같은 명령을 실행합니다.

## 막히면

| 보이는 것 | 할 일 |
|---|---|
| `node` 를 찾을 수 없음 | Node.js 를 설치하고 PowerShell 창을 새로 엽니다. |
| `npm` 스크립트를 찾을 수 없음 | `on-client` 폴더에서 실행했는지 확인합니다. |
| 브라우저가 열리지 않음 | 켠 창이 살아 있는지, 주소의 포트가 맞는지 확인합니다. |
| 「조회 실패」 | 앱을 켠 뒤 「다시 조회」를 직접 누릅니다. 자동으로 다시 읽지 않습니다. |

그 밖의 오류는 [STUDENT_RUNBOOK.md](STUDENT_RUNBOOK.md) 8장을 봅니다. 키·토큰·비밀번호는 어디에도 입력하지 않습니다.
